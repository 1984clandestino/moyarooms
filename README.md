# moyarooms.com

Sito statico di Moya Rooms (MOYA RENT S.R.L.S.), in polacco.

- `index.html` – pagina principale; i dati degli appartamenti sono nell'elenco `APTS` dentro lo script in fondo alla pagina
- `polityka-prywatnosci.html` – privacy e cookie
- `img/` – foto degli appartamenti
- `fonts/` – font Outfit e DM Sans ospitati sul server (licenza SIL OFL 1.1)

Ogni modifica caricata sul ramo `main` viene pubblicata automaticamente su OVH tramite webhook.
